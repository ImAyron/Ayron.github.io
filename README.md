## 🇧🇷 Português

### Sobre

Currículo online de página única, construído em HTML e SCSS e hospedado no **GitHub Pages**. O site reúne experiência profissional, formação acadêmica, habilidades e informações de contato em um layout responsivo.

### Estrutura

```
index.html        Página principal do currículo
assets/scss/      Fontes SCSS (89 arquivos) — edite aqui
assets/css/       CSS compilado, servido pelo site
assets/images/    Imagens e fotos
favicon.ico       Ícone da aba do navegador
```

### Desenvolvimento

O conteúdo textual fica em `index.html`. Para mudanças de estilo, edite os arquivos em `assets/scss/` e recompile para `assets/css/`:

```bash
sass assets/scss/resume.scss assets/css/resume.css
```

Para visualizar localmente, basta abrir `index.html` no navegador, ou servir a pasta:

```bash
python -m http.server 8000
```

### Publicação

O GitHub Pages publica automaticamente a branch `main`. Todo push é refletido no site em poucos instantes.

## 🇺🇸 English

### About

Single-page online resume built with HTML and SCSS, hosted on **GitHub Pages**. The site gathers professional experience, education, skills, and contact details in a responsive layout.

### Layout

```
index.html        Main resume page
assets/scss/      SCSS sources (89 files) — edit here
assets/css/       Compiled CSS served by the site
assets/images/    Images and photos
favicon.ico       Browser tab icon
```

### Development

Text content lives in `index.html`. For styling changes, edit the files under `assets/scss/` and recompile into `assets/css/`:

```bash
sass assets/scss/resume.scss assets/css/resume.css
```

To preview locally, open `index.html` directly, or serve the folder:

```bash
python -m http.server 8000
```

### Publishing

GitHub Pages publishes the `main` branch automatically. Every push shows up on the live site within moments.
